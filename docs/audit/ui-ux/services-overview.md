# UI/UX Audit — Services Overview (`/services`)

## Summary
The overview page is clean, uses a consistent 1/2/3-column card grid, and correctly separates decorative `primary` from interactive `interactive` (the card title correctly shifts to `text-interactive` on hover while the eyebrow/label stays `text-primary`). The main problems are informational, not structural: one service card (Security) silently falls back to a generic placeholder image, there's no filter/sort mechanism at all (fine for 5 items but worth noting since the task asked), and the intro copy claims "10 full-time professionals" which reads oddly small next to five distinct service divisions and could undercut credibility.

## What's Working Well
- Correct primary/interactive split: eyebrow labels and decorative icon dots use `text-primary`/`bg-primary`, while the hover affordance on card titles uses `text-interactive` — exactly matching the intended design system split.
- Full-card click target via absolutely-positioned `<a>` with a descriptive `aria-label` (`Learn more about {service}`) — good for both usability and accessibility.
- `data-animate` scroll-in treatment is applied consistently across cards and process steps.
- Card copy (`serviceDescriptions`) is concrete and specific per service (e.g. "TLB, excavators, tipper trucks..." for Plant Hire) rather than generic marketing fluff — strong information scent for the four services that do have real content and images.
- Responsive grid collapses cleanly from 3 → 2 → 1 columns with a single `gap-6`, no custom breakpoint overrides needed.
- The 5-step "How We Work" process section gives clear expectation-setting before the CTA, reinforcing trust.
