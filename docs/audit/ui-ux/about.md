# UI/UX Audit — About Us (`/about`)

## Summary
The page is structurally solid: consistent section rhythm (`py-16 lg:py-20`), correct use of the new `--primary`/`--interactive` split (eyebrow labels and icon dots use `text-primary`/`bg-primary/10`, the one real CTA link uses `bg-interactive`), and a sensible content order (overview → vision/mission → values → story → stats → why-us → accreditations → team → clients → CTA). The main problems are trust-undermining content states (a "pending" registration displayed with a confirmed checkmark), a visibly broken-looking team section (50%-opacity placeholder photos with real names as alt text), and a handful of small interactive-state and responsive-grid inconsistencies that a fresh, skeptical pass turns up.

## What's Working Well
- Correct, consistent split between `--primary` (eyebrow labels, decorative icon dots, job-title text) and `--interactive` (the one real CTA link) — no stray `bg-primary` on clickable elements found on this page.
- Section rhythm is uniform: every content section uses `py-16 lg:py-20` (or the shared `ContactCTA`/`StatsBar` components), giving a predictable vertical cadence.
- `h2` sizing is consistent throughout (`text-3xl font-bold`), and body copy consistently uses `text-muted-foreground leading-relaxed`.
- Icons are marked `aria-hidden="true"` throughout, keeping the accessibility tree clean since all icons here are purely decorative.
- Good progressive disclosure of trust signals: overview → values → story → hard numbers (`StatsBar`) → differentiators → accreditations → team → client list → CTA is a logical narrative order for a B2B services company.
- Responsive image handling via `Picture` with explicit `width`/`height` and `loading='lazy'` on the hero image avoids layout shift.
